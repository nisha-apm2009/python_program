# Simple Calculator

## 📌 Project Description

This is a simple Python calculator program that performs basic mathematical operations on two numbers.

The program can perform:

* Addition
* Subtraction
* Multiplication
* Division

It also checks whether the user tries to divide by zero.

## 🛠️ Technologies Used

* Python 3

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this project.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python calculator.py
```

## 💻 How It Works

The program asks the user to enter two numbers and then displays the results of the basic arithmetic operations.

### Example

```text
Enter first number: 10
Enter second number: 5

Addition: 15.0
Subtraction: 5.0
Multiplication: 50.0
Division: 2.0
```
